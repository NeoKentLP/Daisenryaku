## 三、命名规范

### 3.1 通用规则

| 规则 | 示例 |
|------|------|
| 全英文小写 | `tank_pz4.png` ✅ `Tank_Pz4.png` ❌ |
| 单词间用下划线 | `heavy_infantry.png` ✅ |
| 不用空格 | `heavy infantry.png` ❌ |
| 兵种前缀 | `inf_rifle_squad.png`, `veh_pz4.png` |
| 国家前缀 (可选) | `ger_pz4.png`, `sov_t34.png` |

### 3.2 命名表

| 类别 | 命名模式 | 示例 |
|------|---------|------|
| 兵种图标 | `{兵种}_{型号}.png` | `infantry_rifle.png`, `vehicle_pz4.png` |
| 地形瓦片 | `{地形id}.png` | `plain.png`, `forest.png`, `city.png` |
| 指挥官头像 | `portrait_{国家}_{编号}.png` | `portrait_ger_01.png` |
| UI图标 | `icon_{功能}.png` | `icon_morale.png`, `icon_ammo.png` |
| UI背景 | `bg_{场景}.png` | `bg_battle.png`, `bg_menu.png` |
| 按钮 | `btn_{状态}_{功能}.png` | `btn_normal_attack.png` |
| 环境装饰 | `env_{名称}.png` | `env_tree.png`, `env_house.png` |

### 3.3 尺寸规范

| 用途 | 基础尺寸 | 建议 | 备注 |
|------|---------|------|------|
| **兵种图标** | 64×64 px | + `@2x` (128×128) | 六边形内切圆约56px |
| **地形瓦片** | 256×256 px | 六边形外接圆直径 | 可无缝拼接 |
| **指挥官头像** | 80×120 px | 统一竖版比例 | 居中构图 |
| **UI图标** | 32×32 px | + `@2x` (64×64) | 统一尺寸集 |
| **UI按钮** | 按需 + 9-patch | 可拉伸 | 建议用 StyleBoxTexture |
| **环境/建筑** | 64×64 px 起 | 按实际比例 | 六边形格内可见 |

## 四、格式要求

| 要求 | 说明 |
|------|------|
| **格式** | PNG (Godot原生支持最好) |
| **背景** | 透明 (导出时选中"透明背景") |
| **颜色** | sRGB |
| **文件编码** | UTF-8 无 BOM 文件名 |
| **@2x 规则** | 同名文件 + `@2x` 后缀，放在同目录 |

示例:
```
assets/sprites/
├── tank_pz4.png          ← 64×64 (基础)
├── tank_pz4@2x.png       ← 128×128 (高清)
├── infantry_rifle.png
└── infantry_rifle@2x.png
```

## 五、导入与使用流程

### 5.1 标准流程

```
你操作:
  ① 准备好图片 (PNG, 透明背景, 正确尺寸)
  ② 放入 assets/ 对应子目录
  ③ Godot 自动生成 .import 文件 (首次打开项目时)
  ④ 通知我文件已就位

我操作:
  ⑤ 代码中引用: preload("res://assets/sprites/tank_pz4.png")
  ⑥ 连接到对应节点 (如 Squad 的 Sprite2D)
  ⑦ 运行验证显示正确
```

### 5.2 你自行在编辑器中替换

如果你有 Godot 编辑器操作经验:

```
① 打开对应的 .tscn 场景文件
② 找到 Sprite2D 或 TextureRect 节点
③ 在 Inspector 面板 → Texture 属性 → 拖入你的图片
④ 保存 (Ctrl+S)
⑤ 运行游戏查看效果
```

### 5.3 `.import` 文件说明

每个图片文件会自动生成同名的 `.import` 文件:
```
assets/sprites/tank_pz4.png
assets/sprites/tank_pz4.png.import
```

- `.import` 由 Godot 自动管理，**不要手动编辑**
- 如果需要重新导入: 在 Godot 编辑器中选中图片 → 右键 → Reimport
- 如果需要修改导入参数: 双击 `.import` 文件进入 Import Dock

## 七、注意事项

| 注意事项 | 说明 |
|---------|------|
| **不用的图片及时删除** | Godot 会在 `.import` 中留下引用，需同步清理 |
| **PNG 压缩** | 体积过大影响加载速度，建议用 TinyPNG 压缩 |
| **@2x 不是必须的** | 第一阶段可以只用基础尺寸，后期再补高清版 |
| **Sprite 朝向** | 六边形是 pointy-top，Sprite 默认朝上，需要时我代码 rotate |
| **九宫格 (9-patch)** | UI按钮/面板建议用可拉伸的9-patch图，自适应不同分辨率 |
| **Alpha 通道** | PNG 必须保留透明通道，不要导出为不透明格式 |

## 八、常见问题

### Q: 我提供了图片但游戏里没显示?
A: 可能原因: ① 文件路径不对 ② 图片太大超出六边形范围 ③ `.import` 未刷新 (右键→Reimport)

### Q: 同一个兵种不同国家能用不同颜色吗?
A: 可以。两个方案: 
   - 方案A: 每个国家独立图片 (`ger_infantry.png`, `sov_infantry.png`)
   - 方案B: 同一张图 + 代码调色 (modulate 改 RGB)
   
### Q: 图片要带边框吗?
A: 不用。边框由代码里的 Polygon2D 或 StyleBox 画，图片只负责内容。

### Q: 我想用 SVG 可以吗?
A: Godot 支持 SVG 导入，但建议导出为 PNG 再用。SVG 在运行时缩放性能开销较大，且部分复杂 SVG 解析有问题。
