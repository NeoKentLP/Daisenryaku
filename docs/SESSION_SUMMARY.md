## 三、UI完整流程 (新游戏→第一关结束)

```
主菜单 → [新游戏]
         → [国家选择] 轮播选国家
         → [指挥官创建] 4卡横排, 可重掷/编成/改名
         → [部署] 左栏部队列表→选中→操作按钮→点地图放置
         → [战场主界面]
              ├→ [部队详情] 点击己方部队
              ├→ [战斗预览] 选动作→点目标→期望值
              │   → [战斗过程] 确认→自动动画播放
              │       → [战斗详情] 流水账弹窗
              └→ [胜利结算] 达成胜利条件
                  → 基地 (后续设计)
```
