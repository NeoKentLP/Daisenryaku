## 1. 三层结构：兵种→部队→成员

### 1.1 层级定义

```
兵种(UnitType) ──模板定义──→ 部队(Squad) ──招募实例──→ 成员(Member)

  例:                               
  德国步兵班(兵种)    第一步兵班(部队)    步枪手×8 + 班长×1 + 机枪手×1(成员)
```

### 1.2 各层级说明

**兵种 (UnitType)** — 模板
- 定义部队的编制组成（每类成员各多少）
- 定义招募成本和解锁条件
- 不可直接操作

**部队 (Squad)** — 战场实体
- 玩家命名（系统自动生成默认名，可修改）
- 拥有等级、士气、经验等独立属性
- 在地图上占一格
- 包含多个成员，战力取决于存活成员

**成员 (Member)** — 个体
- 有独立的名称（编制名，如"步枪手"）
- 有独立的HP、武器、装备
- HP归零时阵亡并从部队移除
- 每个成员有固定的**成员类型**

### 1.3 成员类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 步兵(Infantry) | 徒步作战人员 | 步枪手、机枪手、班长 |
| 轻型载具(LightVehicle) | 轻装甲/无装甲车辆 | 吉普车、摩托车、侦察车 |
| 重型载具(HeavyVehicle) | 重装甲战斗车辆 | 坦克、装甲运兵车 |
| 火炮(Artillery) | 间瞄火炮/固定武器 | 榴弹炮、迫击炮 |
| 直升机(Helicopter) | 旋翼飞行器 | 侦察直升机、运输直升机 |
| 固定翼(FixedWing) | 固定翼飞机 | 战斗机、轰炸机 |
| 骡马(PackAnimal) | 驮兽 | 马匹、骡子 |

### 1.4 编制示例

| 兵种 | 编制 |
|------|------|
| 德国步兵班 | 班长(步兵)×1 + 步枪手(步兵)×6 + 机枪手(步兵)×1 + 副射手(步兵)×1 = 10人 |
| 装甲掷弹兵班 | 班长(步兵)×1 + 步兵×6 + MG机枪组(步兵)×2 + 装甲运输车(重型载具)×1 |
| 三号坦克 | 车长(步兵)×1 + 炮手(步兵)×1 + 驾驶员(步兵)×1 + 装填手(步兵)×1 + 坦克(重型载具)×1 |
| 105mm榴弹炮班 | 炮长(步兵)×1 + 炮手(步兵)×4 + 弹药手(步兵)×2 + 牵引车(轻型载具)×1 |

> 注意：成员类型≠编制名。坦克的全体乘员都是"步兵"类型，但编制名为车长/炮手等。
> 成员类型影响：武器伤害匹配、移动地形消耗、载具搭载限制。

## 2. 属性体系

### 2.1 兵种模板属性 (UnitType)

| 属性 | 说明 |
|------|------|
| ID | 唯一标识 |
| 名称 | 如"德国步兵班" |
| 成本 | 招募所需货币 |
| 解锁条件 | 所需关卡进度 |
| 编制表 | 包含哪些类型的成员各多少个 |

### 2.2 部队属性 (Squad)

| 属性 | 说明 |
|------|------|
| 名称 | 系统自动命名（如"第一步兵班"），玩家可改 |
| 兵种模板 | 所属UnitType |
| 等级 | 乌合之众/新兵/老兵/精锐/王牌 |
| 经验 | 当前经验值 |
| 士气 | 0-100，受战况影响 |
| 状态 | 由士气决定：混乱/正常/高昂/狂热/溃败 |
| 位置 | 地图Hex坐标 |
| 朝向 | 指向的Hex方向（用于方向装甲判定） |
| AP | 行动点（4） |
| 成员列表 | 当前存活的成员数组 |

### 2.3 成员属性 (Member)

| 属性 | 说明 |
|------|------|
| ID | 唯一标识 |
| 名称 | 编制名，如"步枪手"、"车长" |
| 成员类型 | 步兵/轻型载具/重型载具/火炮/直升机/固定翼/骡马 |
| HP | 生命值 |
| 移动类型 | 步行/轮式/履带/骡马/飞行 |
| 移动力 | 基础移动格数 |
| 命中(BS) | 百分比值，如70=70% |
| 护甲(Armor) | 对抗穿透的值。载具分方向见[第11章](#11-方向装甲) |
| 回避(Evasion) | 闪避修正（体型小/速度快→高） |
| 隐蔽(Concealment) | 隐藏修正（草丛/掩体等） |
| 技能 | 特殊能力列表 |
| 载具容量(可选) | 仅载具：可搭载的成员类型列表(步兵/轻型载具/重型载具等) |
| 装备栏 | 当前装备的武器列表 |

## 3. 士气与状态

### 3.1 士气分段与状态

| 士气范围 | 状态 | 效果 |
|----------|------|------|
| 0 | 溃败 | 单位不受控制，自动向己方撤退 |
| 1-20 | 混乱 | 命中率降低，无法使用技能 |
| 21-70 | 正常 | 无修正 |
| 71-90 | 高昂 | 命中率提升 |
| 91-100 | 狂热 | 命中率+伤害提升 |

### 3.2 士气影响因素

| 事件 | 士气影响 |
|------|---------|
| 己方成员阵亡 | 减少 |
| 部队受攻击 | 减少 |
| 友军部队阵亡（邻近格） | 减少 |
| 击杀敌人 | 增加 |
| 回合末 | 小幅恢复 |
| 占领据点 | 增加 |
| 指挥官技能 | 可增减 |

| 沼泽 | 10% | -10% | ❌ |
| 森林 | 20% | -10% | ✅ |
| 工厂 | 20% | -10% | ❌ |
| 城市 | 30% | -15% | ✅ |
| 指挥部 | 30% | -10% | ❌ |
| 山地 | 40% | -20% | ❌ |
| 废墟 | 30% | -15% | ✅ |

### 4.4 战壕等级

工兵可建造，步兵最高可建到Lv2。可在现有战壕上升级。

| 等级 | 掩护减伤 | 命中惩罚 | 建造耗时 | 建造者 |
|------|---------|---------|---------|--------|
| 1级战壕 | 10% | -5% | 即时 | 步兵/工兵 |
| 2级战壕 | 20% | -10% | 1回合 | 步兵/工兵 |
| 3级战壕 | 30% | -15% | 2回合 | 仅工兵 |
| 4级战壕 | 40% | -20% | 3回合 | 仅工兵 |
| 5级战壕 | 50% | -25% | 4回合 | 仅工兵 |

- 战壕属于CQB地形
- 战壕内车辆的通行限制见§4.2

### 4.5 堡垒等级

仅工兵可建造。

| 等级 | 掩护减伤 | 命中惩罚 | 建造耗时 |
|------|---------|---------|---------|
| 1级堡垒 | 40% | -10% | 2回合 |
| 2级堡垒 | 55% | -15% | 4回合 |
| 3级堡垒 | 65% | -20% | 6回合 |

- 堡垒属于CQB地形
- 堡垒可被工兵爆破或火炮摧毁

### 4.6 地形效果叠加规则

- 攻击方所在格的地形提供**命中惩罚**
- 防守方所在格的地形提供**掩护减伤**
- 双方在同一格时（近战/CQB），使用该格的掩护减伤
若攻击方和防守方在同一格（近战），使用该格的掩护减伤。

## 5. 武器系统

### 5.1 武器属性

| 属性 | 说明 |
|------|------|
| 名称 | 如"Kar98k步枪" |
| 伤害类型 | 该武器的主要伤害类型 |
| 对各类型伤害 | 对不同成员类型的伤害值表 |
| 伤害波动 | ±百分比（默认±20%，可受技能/指挥官影响） |
| 护甲穿透 | 穿透判定修正值 |
| 命中加成 | 修正BS的值 |
| **压制力** | **对目标部队产生的压制值** |
| 射程(最小) | 最小攻击距离（0=近战） |
| 射程(最大) | 最大攻击距离 |
| 弹药 | 当前弹药/最大弹药 |

### 5.2 伤害类型与伤害值

**设计原则**：每种武器对不同的成员类型有独立的伤害值。若为0则无法对该类型造成伤害。
无需效率系数，直接查表。

```
示例 — 75mm坦克炮:
  对步兵(Infantry):    15    (高爆弹溅射)
  对轻型载具(Light):   30
  对重型载具(Heavy):   50
  对火炮(Artillery):   30
  对直升机(Heli):      10    (不易命中)
  对固定翼(Fixed):     0     (无法对空)
  对骡马(Pack):        15

示例 — MG42机枪:
  对步兵(Infantry):    25
  对轻型载具(Light):   8
  对重型载具(Heavy):   0     (无法穿透)
  对火炮(Artillery):   8
  对直升机(Heli):      5
  对固定翼(Fixed):     0
  对骡马(Pack):        20
```

> 对每种类型的伤害值在武器定义时填写，0=无法造成伤害。

### 5.3 交火时的武器选择

- 选择目标部队后，弹出**武器汇总选择界面**
- 按武器类型汇总显示（如"步枪×6 弹药30""机枪×2 弹药8"）
- 自动剔除：弹药0 / 射程不到 / 对目标所有成员类型的伤害值均为0
- 默认全部勾选
- 玩家可取消勾选特定武器类型（节省弹药）
- 确认后执行全队交火

## 6. 战斗流程

### 6.1 交火流程（部队对部队）

```
选己方部队 → 选目标敌方部队 → 选武器(默认全选) → 确认
                                                      ↓
                                              逐一成员逐一武器结算
                                                      ↓
                                              汇总结果展示
```

### 6.2 结算顺序

```
for each 攻击方成员:
    for each 该成员的武器(且被选中、有弹药、射程够、伤害值>0):
        ① 命中判定
        ② 穿透判定(如命中)
        ③ 伤害计算(如穿透)
        ④ 随机分配命中目标
        记录结果

汇总展示:
  "步枪命中3次，造成12点伤害"
  "机枪命中1次，造成8点伤害"
  "敌方阵亡2人"
```

### 6.3 三层判定

```
① 命中判定:
   最终命中率 = BS(攻击者) + 武器命中加成 + 士气修正
              - 目标地形命中惩罚 - 目标回避 - 目标隐蔽 - 射程修正
              - ZOC惩罚(若攻击者在敌方ZOC内)
   特殊: CQB突击时按[第12章](#12-近战规则cqb系统)武器CQB有效性修正命中率
   BS和各修正最终以百分比显示（如BS=70 → "70%"）
   Roll d100 ≤ 最终命中率 → 命中，进入穿透

② 穿透判定:
   最终穿透 = 武器护甲穿透 + 随机骰(±X)
   ≥ 目标护甲(Armor) → 穿透成功
   < 目标护甲 → 未穿透，伤害0

③ 伤害计算:
   最终伤害 = 武器对目标成员类型的伤害值 × (1 ± 随机波动%) × 掩护减伤
   压制效果: 伤害波动范围受压制值影响(见[第18章](#18-火力压制系统))
   CQB突击: 双方同时开火(见[第12章](#12-近战规则cqb系统))
   向下取整，最低1
```

### 6.4 命中目标分配

- 每个武器的伤害在敌方部队成员中 **随机分配**
- 同一成员可能被多次命中
- 成员HP归零则阵亡移除
- 后续武器从剩余成员中随机分配

### 6.5 近战特殊规则

射程最小=0的武器视为近战武器，适用[第12章 CQB系统](#12-近战规则cqb系统)。

## 7. 侦查与视野系统

### 7.1 战争迷雾三态

```
■ 未探索（全黑）    →  完全没有探索过的区域，不显示地形
■ 已探索（地形轮廓） →  曾经看到过但当前无视野，显示灰色地形，不显示敌方单位
□ 可见             →  在当前友军视野范围内，正常显示地形和敌方单位
```

- **视野全共享**：任一友军看到 = 全军可见
- 未探索区域全黑，直到有单位进入视野范围内才揭示

### 7.2 视野范围

| 成员类型 | 基础视野 |
|---------|---------|
| 步兵 | 2格 |
| 侦察单位 | 5格 |
| 坦克 | 2格 |
| 火炮 | 3格 |
| 直升机 | 6格 |

- 部队视野 = 所有成员视野的**最大值**
- 站**山地格**：视野+2格，且可越过低地障碍（无视森林等阻挡）

### 7.3 视线遮挡

| 地形 | 阻挡视线 |
|------|---------|
| 山地 | ✅ |
| 森林 | ✅ |
| 其他 | ❌ |

- 采用**格子属性法**：计算A到B的视线时，检查路径上经过的格子是否含阻挡属性
- 若路径上任一格子有阻挡属性 → 视线被挡住，不可见
- 站在山地上的单位可越过低地障碍（森林阻挡被忽略）

### 7.4 侦查技能

- **侦察单位独有主动技能**
- 消耗 **1AP** 使用
- 选择一个**视野内的敌方部队**作为目标
- 本回合内，对该目标部队的**命中率提升 + 伤害提升**（具体数值待定）
- 提升效果仅对该目标有效，对其他敌人无加成

## 8. ZOC控制区域

### 8.1 基本规则

- 部队对其周围6格施加控制区域
- ZOC不区分方向，六格全包围

### 8.2 进入ZOC

- 敌方部队进入我方ZOC时**立即停止移动**

### 8.3 在ZOC内

| 效果 | 说明 |
|------|------|
| 远程命中下降 | 在ZOC内时远程攻击命中率降低 |
| 每回合+5压制 | ZOC持续产生压制效果 |

### 8.4 离开ZOC

离开ZOC需要同时满足两个条件：

1. **双倍AP消耗**：从ZOC格移动到非ZOC格时，该步消耗2AP（而非1AP）
2. **借机攻击**：触发一次敌方自动攻击
   - 从相邻的敌方部队中选择**攻击力最高的一个**执行
   - 弹出窗口显示攻击结果
   - 消耗防守方**弹药**
   - 防守方**士气小幅下降**（开火消耗精力）

### 8.5 与压制系统的互动

- 进入ZOC不立即产生压制
- 在ZOC内每回合自动**+5压制**

## 11. 方向装甲

### 10.1 概念

载具（重型载具/部分轻型载具）在不同方向上护甲不同，反映真实装甲设计：
- 正面最厚
- 侧面中等
- 后面最薄
- 顶部/底部（未来扩展）

### 10.2 护甲方向定义

采用六边形方向的简化方案，一个单位有6面装甲值：

```
       Front
         ↑
    FL   ↑   FR
      ↖  ↑  ↗
  ←—←——←——←——→—→
      ↙  ↓  ↘
    RL   ↓   RR
         ↓  
        Rear
```

| 方向 | 说明 |
|------|------|
| F (Front) | 正面 |
| FL (Front-Left) | 前左侧 |
| FR (Front-Right) | 前右侧 |
| RL (Rear-Left) | 后左侧 |
| RR (Rear-Right) | 后右侧 |
| R (Rear) | 后面 |

### 10.3 攻击方向判定

- 攻击者的方向相对防御者的朝向决定使用哪个方向的护甲值
- 每个兵种/成员可单独定义各方向护甲值
- 非载具类型（步兵等）使用统一护甲值，不分方向

### 10.4 部队朝向

- 部队在移动结束时自动面朝移动方向
- 部队在攻击时面朝攻击目标方向
- 玩家可手动调整朝向（消耗AP？待讨论）

## 12. 近战规则（CQB系统）

### 12.1 概述

近战在游戏中体现为**CQB（Close Quarters Battle）**——在特定地形下的近距离突击作战。
- 不是通用战斗方式，而是特定场景下的强力战术选择
- 高伤害、高消耗、双方都有损失风险

### 12.2 适用地形

突击指令仅可在以下地形使用：
- 城市(city)
- 森林(forest) 
- 废墟(ruins)
- 战壕(trench)
- 堡垒(bunker)

这些地形本身已有远程命中惩罚（见§4.3），与CQB机制叠加。

### 12.3 触发方式

- 主动指令「**突击**」（Assault）
- 仅在CQB地形可用
- 消耗 **3AP**
- 攻击方和防御方必须处于**相邻格**

### 12.4 结算规则

**同时开火**：攻防双方各自计算对对方的伤害，无先后顺序。
```
攻方伤害 → 基于攻方CQB有效武器
防方伤害 → 基于防方CQB有效武器 
双方同时受伤害 → 可能两败俱伤
```

### 12.5 武器CQB有效性

| 武器类型 | CQB效果 | 说明 |
|---------|---------|------|
| 冲锋枪(SMG) | ★★★ 优秀 | MP40、Thompson、PPSh-41 |
| 手枪 | ★★★ 优秀 | 近身灵活 |
| 卡宾枪 | ★★ 良好 | G43、M1卡宾 |
| 突击步枪 | ★★ 良好 | StG44（介于冲锋枪和步枪之间） |
| 步枪(栓动) | ★ 较差 | Kar98k、莫辛-纳甘 |
| 轻机枪(LMG) | ★ 较差 | MG42（火力强但笨重） |
| 重型武器 | ☆ 不可用 | 坦克炮、榴弹炮、重机枪（CQB无效） |

**效果体现方式**：
- CQB中无法使用重型武器
- CQB中SMG/手枪获得**命中加成**和**伤害加成**
- CQB中栓动步枪获得**命中惩罚**
- LMG在CQB中维持基础命中但无加成

### 12.6 战斗示例

```
步兵班(含MP40×2 + Kar98k×6) 突击 敌方步兵班(含Kar98k×8)

攻方可用武器：MP40×2(优秀) + Kar98k×6(较差)
守方可用武器：Kar98k×8(较差)

攻方命中率：MP40获得CQB加成，Kar98k受CQB惩罚
守方命中率：所有Kar98k受CQB惩罚

结算：双方同时开火，各自计算损失
——攻方因有MP40占优势
——守方如果人数占优仍可能造成可观伤害
```

### 12.7 限制

- **远程武器无效化**：在CQB地形中，超出相邻格的远程攻击受到高额命中惩罚（§4.3已覆盖）
- **载具限制**：坦克/装甲车在CQB地形中无法使用突击指令（可正常远程攻击）
- **补给单位限制**：补给部队不可突击

### 12.8 近战武器（射程0）

部分武器天然射程最小=0（如刺刀、手枪），但这些在二战中场景有限。当无远程弹药时，近战为最后手段：
- 使用射程0武器时，视为普通攻击（非CQB突击）
- 不享受CQB加成
- 仅当武器弹药为0且敌人相邻时可用

## 13. 世界阶段玩法

> 自由行走+据点交互的半开放战役模式。

### 13.1 背景设定

- **时间**: 1940-2000（游戏内不显示具体年份，仅以时代划分）
- **地点**: 混乱之地 — 后殖民时代非洲，殖民势力撤出后留下的权力真空地带
- **主角**: 一名指挥官 + 3名战友（不同兵种指挥官），来到此地寻找仇敌复仇
- **仇敌**: 一名特定的敌方指挥官，曾背叛主角
- **剧本**: 复仇之旅（纯沙盒，最终战役结束）

### 13.2 时代系统

| 时代 | 解锁回合 | 特征 |
|------|---------|------|
| 时代1 | 开局 | 二战装备：Kar98k、谢尔曼、T-34、P-51 |
| 时代2 | 20回合 | 早期冷戰：F-86、米格15、AK47、百夫长坦克 |
| 时代3 | 50回合 | 中期冷戰：直升机普及、ATGM、T-62、M60 |
| 时代4 | 90回合 | 越战时期：M16、T-72、先进对空导弹 |
| 时代5 | 140回合 | 现代化：M1艾布拉姆斯、挑战者、第三代战机 |

- 固定回合触发，据点商店刷新对应时代的装备
- 部队可升级装备以匹配新时代

### 13.3 世界地图

- **10-15个据点**分布在地图上
- 据点有**规模**(大/中/小) + **类型**(功能) 两个维度
- 据点之间**自由行走**，移动耗时消耗回合
- 行走过程中**概率随机遇敌**触发战斗
- 每个行动消耗回合，推进时代计数器

### 13.4 据点类型

| 据点类型 | 主要功能 |
|---------|---------|
| 城市 | 高级招募、交易、情报 |
| 小镇 | 基本补给、招募 |
| 村庄 | 补给、休息恢复士气、随机事件 |
| 港口 | 海上贸易路线、特殊商品 |
| 机场 | 空运、空中支援任务 |
| 工厂 | 装备生产/改装（消耗资源） |
| 矿山 | 产出矿物，可交易 |
| 油田 | 产出燃料，可交易 |
| 大国基地 | 高级武器、精英招募、特殊任务 |
| 野外 | 遇敌、探索事件 |

### 13.5 势力体系

**本地势力** — 小国内部的多个对立派系：
- 相互敌对，各有控制区域
- 玩家可选边支持，助其统一该国
- 统一后获得一段和平期，之后可能再次分裂内战
- （具体规则待细化）

**大国势力** — 美/苏/英/法/德/中：
- 在混乱之地有军事基地或影响力据点
- 出售对应国家特色的武器装备
- 发布特殊任务
- 大国之间关系影响玩家可接的任务

### 13.6 补给系统

5种补给，共享**移动车队容量**：

| 类型 | 消耗 | 耗尽后果 |
|------|------|---------|
| 食物 | 每回合每人 | 士气下降→减员 |
| 弹药 | 每场战斗 | 无法攻击 |
| 燃料 | 每回合(车辆) | 车辆无法移动 |
| 备件 | 战损修复 | 装备损坏无法修 |
| 医疗用品 | 战伤恢复 | 伤兵无法恢复 |

- 容量由运输车辆数量和类型决定
- 可在据点购买补充
- 补给归零触发负面事件

### 13.7 战役循环

```
初始生成：主角指挥官+3战友随机生成，进入混乱之地
    ↓
自由探索世界地图（行走→随机遇敌→到达据点）
    ↓
据点交互（交易/招募/接任务/休息/补充补给）
    ↓
发展壮大 → 寻找仇敌线索 → 最终决战
    ↓
胜利通关
```

- 纯沙盒，无强制主线
- 战斗中可撤退
- 无限存档
- 击败仇敌所在的最终战役后通关

## 14. 指挥官系统

### 14.1 指挥官池

- 独立于部队的卡牌式指挥官池
- 通过**商店刷新**消耗货币招募
- 每个部队必须任命一名指挥官，任命后绑定
- 战斗中不可更换，**部署阶段/战略阶段**可重新分配
- 指挥官可以从部队**卸载**，部队变为无指挥状态（不可出战，但保留编制）

### 14.2 招募

- 商店定期刷新指挥官
- 每个指挥官有：背景模板（决定初始技能）+ 随机名字 + 初始技能
- 稀有度：新兵 / 老兵 / 英雄（影响品质技能数量）

### 14.3 初始化技能（每位指挥官固定+概率拥有）

| 类型 | 数量 | 说明 |
|------|------|------|
| 背景技能 | 固定1个 | 由背景模板决定，兵种绑定（匹配对应部队时生效） |
| 天赋技能 | 固定1个 | 由天赋特质决定，通用效果 |
| 品质技能 | 0-3个 | 按稀有度概率获得：新兵50%×1 / 老兵20%×2 / 英雄5%×3 |

### 14.4 养成线

升级体系（共10级）：
- 初始获得：背景+天赋+品质（共2-5个技能）
- 每升一级：从3个备选中选择1个（新技能Lv1 或 已有技能升级为Lv2）
- 备选池构成：固定(背景相关) + 通用 + 等级解锁 + 概率
- 技能升级：中幅度提升效果

### 14.5 等级技能

| 等级 | 技能名 | 效果 |
|------|--------|------|
| Lv5 | 部队扩张 | 所属部队编制规模×2（不占用选择名额） |
| Lv10 | 全员整编 | 所属部队编制规模×3（不占用选择名额） |

### 14.6 经验获取

```
通关基础:    +100XP
伤害奖励:    +1XP/10伤害
击杀奖励:    +10XP/击杀
目标奖励:    +50XP/任务目标
低伤亡奖:    +20XP(阵亡<3人)
难度系数:    简单×1.0 / 普通×1.5 / 困难×2.0
```

（具体数值可在实现时调整）

### 14.7 指挥官与战斗的关系

- 指挥官不占部队编制、不参与战斗、不作为攻击目标
- 指挥官技能在战斗中由玩家主动施放（主动技能消耗部队AP）
- 光环被动技能持续生效
- 指挥官没有HP，不会阵亡。部队被歼灭→指挥官回池子

**指挥官主动技能示例（部分）**：

| 技能 | AP | CD | 效果 |
|------|----|----|------|
| 鼓舞士气 | 1 | — | 所属部队恢复士气 |
| 精确射击 | 1 | — | 本回合指定武器命中+20% |
| 火力压制 | 2 | — | 目标部队本回合命中-15% |
| 战术撤退 | 1 | — | 免费后撤1格(无视ZOC) |
| 战场侦查 | 1 | — | 揭示周围2格敌军 |
| 铁壁防御 | 1 | — | 本回合掩护减伤翻倍 |
| **呼叫炮击** | **3** | **3回合** | **见下方** |

**呼叫炮击规则**：
- 指挥官所属部队消耗3AP，选择地图上一个目标格
- 场上任意一支己方炮兵部队（未进行过普通攻击的）响应
- 消耗响应方的弹药向目标格开火
- 该炮击**不计入**响应方的「已攻击」状态，响应方仍可进行普通攻击
- 同一门炮弹药够可多次响应
- 无距离限制

## 15. 编成系统

### 15.1 入口

- **世界地图**常驻「编成」按钮
- **部署阶段**也可直接进入

### 15.2 核心操作

| 操作 | 说明 | 限制 |
|------|------|------|
| 任命指挥官 | 从指挥官池选择任命到部队 | 每部队限1名 |
| 卸载指挥官 | 将指挥官卸下，部队变为不可出战状态 | 保留编制 |
| 更换指挥官 | 替换部队的现任指挥官 | 部队不能无指挥出战 |
| 装备更换(单换) | 逐个成员更换武器/装备 | 需储备库或商店 |
| 装备更换(批量) | 部队内同类型成员统一换装 | 同上 |
| 补充兵员 | 补满阵亡成员 | 仅限招募据点 |
| 解散部队 | 移除部队，回收部分资源 | 不可撤销 |
| 查看储备 | 管理储备库装备 | — |

### 15.3 补充兵员

- 必须在**招募据点（城市/征兵站）**才能执行
- 消耗货币
- 阵亡成员被替换为「乌合之众」等级的新兵
- 部队整体经验因新兵加入被**拉低**（平均计算），可能降级

### 15.4 部队经验与补充的关系

```
部队总经验 = sum(成员经验)
新兵加入后平均经验 = 总经验 / 新总人数
若平均经验低于当前等级阈值 → 部队降级
```

### 16.4 限制

- 出战名额由任务规模决定（小规模≤3，大规模≤6）
- 每支部队必须有一名指挥官才可出战
- 出战部队在战斗中获得经验

## 17. 装备系统

### 17.1 核心概念

不是数值强化（+1/+2），而是**更换为同系列的不同子型号**，反映真实历史改进。

**示例 — 四号坦克系列：**
```
四号D型 (Era1, 短75mm炮, 基础型)
  ├─ 四号F2型 (Era1, 长75mm炮, 反坦克能力↑)
  │    ├─ 四号G型 (Era2, 装甲↑)
  │    │    └─ 四号H型 (Era2, 裙板装甲, 最终型)
  │    └─ 四号突击炮 (Era2, 无炮塔, 正面装甲↑↑)
  └─ 四号J型 (Era2, 简化版, 成本↓)
```

### 17.2 解锁条件

子型号解锁 = **时代 + 势力关系**：

| 示例 | 时代 | 势力关系 |
|------|------|---------|
| 四号F2 | Era1 | 基础型，默认解锁 |
| 四号G/H | Era2 | 需德国关系≥友好 |
| T-62 | Era3 | 需苏联关系≥友好 |
| M16步枪 | Era4 | 需美国关系≥友好 |

### 17.3 改装条件

- 必须在**工厂/城市/大国基地**据点启动改装
- 消耗**货币**
- 部分改装消耗**备件**
- **不需停留**：启动改装后部队可继续行动
- 改装耗时：X回合后自动完成，装备生效

### 17.4 缴获系统

- 战斗胜利后**概率掉落**敌方装备
- 基础概率受战果影响（大胜↑，惨胜↓）
- 掉落装备存入**储备库**

### 17.5 储备库

- 存放所有备用装备：未使用的武器、缴获品、换下的旧型号
- 可在编成界面中自由分配储备装备给部队
- 可在据点**出售**储备库中的装备换取货币

### 17.6 换装方式

| 方式 | 说明 |
|------|------|
| 单换 | 逐个成员更换武器/装备 |
| 批量 | 部队内同类型成员统一换装 |
| 来源 | 储备库取出 / 据点商店购买 |

## 18. 火力压制系统

### 18.1 概述

火力压制是独立于士气的第二负面状态系统，反映部队被敌方火力压制、难以有效作战的状态。

- **层级**：部队级（整支部队共享一个压制值）
- **范围**：0-100
- **与士气的关系**：互相影响但独立计算

### 18.2 压制来源

| 来源 | 压制量 |
|------|--------|
| 受到攻击 | 武器压制力 × 命中次数（见武器属性） |
| 进入敌方ZOC | +5/回合 |
| 被包围（与多个敌军相邻） | +10/回合 |

### 18.3 压制效果

```
伤害波动范围整体下移：

  无压制时:   基础伤害 × (1 ± 20%)          ← 正常范围
  压制=50时:  基础伤害 × (1 - 20% ~ 1 - 10%)  ← 上限降低
  压制=100时: 基础伤害 × (1 - 40% ~ 1 - 30%)  ← 上限下限都降低

  简单公式:
    伤害波动下限 = -20% - (压制值 × 0.2%)
    伤害波动上限 = +20% - (压制值 × 0.5%)
    例: 压制50 → 下限-30%, 上限-5%

  压制>60时: 部队不可使用主动技能
```

### 18.4 压制恢复

| 条件 | 恢复量 |
|------|--------|
| 每回合自动恢复 | 20点 |
| 待在掩体/城市中 | 额外+10点 |
| 补给耗尽时 | 无法恢复 |
| 士气<30时 | 恢复速度减半 |

### 18.5 与士气的互动

```
士气↓30以下 → 压制恢复速度减半
压制>50     → 每回合额外 -5士气
士气溃败(0) → 压制固定为100，不恢复
```

### 18.6 武器压制力

每把武器新增属性 `suppression_power`（压制力）：

| 武器示例 | 压制力 |
|---------|--------|
| Kar98k步枪 | 5 |
| G43半自动 | 6 |
| StG44突击步枪 | 8 |
| MG42机枪 | 25 |
| 重型机枪 | 35 |
| 75mm轻炮 | 30 |
| 105mm榴弹炮 | 45 |
| 150mm重炮 | 55 |
| 坦克炮(短75) | 10 |
| 坦克炮(长75) | 15 |
| 迫击炮(81mm) | 25 |

> 武器压制力在§5.1武器属性表中新增。

## 19. 弹药与后勤系统

### 19.1 弹药管理（类似装甲军团）

每把武器按**使用次数**计算弹药量：

| 武器类型 | 弹药量（使用次数） |
|---------|-----------------|
| 步枪(Kar98k/G43) | 20次 |
| 突击步枪(StG44) | 25次 |
| 轻机枪(MG42) | 40次 |
| 冲锋枪(MP40) | 20次 |
| 坦克炮(长75) | 30发 |
| 坦克炮(短75) | 25发 |
| 迫击炮 | 15发 |
| 榴弹炮(105mm) | 10发 |

**消耗系数**：每种武器有 `supply_cost`（弹药换算系数），反映每次补充消耗的补给池资源量。区分武器弹药和补给池消耗：
- 武器弹药：战斗中每次攻击消耗**1发**武器弹药（战斗内跟踪，归零无法攻击）
- 补给池消耗：战后补充时，按换算系数从补给池扣除
  - 步枪系数1：补满20发消耗20补给
  - 坦克炮系数5：补满30发消耗150补给

### 19.2 全局补给池

5种资源统一管理：

| 资源 | 换算系数 |
|------|---------|
| 食物 | 1 |
| 弹药 | 1 |
| 燃料 | 1 |
| 备件 | 1 |
| 医疗用品 | 1 |

- **当前版本不设容量上限**，补给池为全局无限池
- 补给消耗从补给池直接扣除
- 在据点补充/购买补给增加池中存量

### 19.3 补给部队

**命名**：补给部队（非"车队"），初期为骡马补给队，后期可升级为卡车补给队、直升机补给队。

**属性**：
- 是一支部队（需要指挥官）
- 无战斗力或战斗力很弱
- 可在战场上建造**补给站**
- 可为相邻友军提供补给/治疗/维修

### 19.4 补给站

**建造**：
- 补给部队在地图上停留X回合（建造耗时）
- 消耗**货币**
- 建造期间补给部队不可移动（移动则进度重置）
- 补给站数量有限，有**冷却时间**

**功能**：
- 固定在地图某一格
- 可为相邻友军提供弹药补充、治疗、维修
- 补给站本身无战斗力

**被占领**：
- 敌方部队踩到补给站所在格 → 补给站被**破坏**（不可使用）
- 敌人无法利用我方补给站

### 19.5 战斗中补充弹药

| 方式 | 条件 | 效果 |
|------|------|------|
| 补给站补充 | 部队在补给站相邻格 | 消耗目标1AP，弹药补满 |
| 补给部队补充 | 部队在补给部队相邻格 | 消耗目标1AP，弹药补满 |
| 战后自动补充 | 战斗结束 | 自动消耗全局补给池补满 |

### 19.6 治疗与维修

在补给站或补给部队相邻格可执行：

| 指令 | 消耗 | 效果 |
|------|------|------|
| 治疗 | 医疗用品（恢复HP×2） | 伤兵恢复HP |
| 维修 | 备件（恢复HP×1） | 载具恢复HP |

### 19.7 指挥官应急技能

部分指挥官拥有应急技能：

| 技能 | AP消耗 | 效果 | 说明 |
|------|--------|------|------|
| 应急治疗 | 1AP | 恢复部队HP总量的15% | 无需补给站 |
| 战场抢修 | 1AP | 恢复载具HP总量的15% | 无需补给站 |
| 弹药调配 | 1AP | 恢复一个武器弹夹 | 无需补给站 |

## 20. 工兵与战场工程

### 20.1 工兵兵种

工兵是**独立兵种模板**，有完整的编制和指挥官系统。

**编制示例 — 工兵班**：
```
班长(步兵)×1 + 工兵(步兵)×6 + 爆破手(步兵)×1 + 工具驮马×1
```

**载具工兵**：
- 工兵可配备载具（装甲工兵车、架桥坦克、扫雷坦克等）
- 配备载具的工兵部队仍视为工兵，可使用全部工兵指令
- 载具工兵的移动力和防护优于徒步工兵

**特点**：
- 战斗力和普通步兵相近或略弱（携带工程装备负重较大）
- **CQB能力良好**：在城市/战壕/废墟中作战有优势
- 可使用特殊指令（建造/排雷/爆破/修复）

### 20.2 工兵变种

| 类型 | 战斗能力 | 工程能力 | 说明 |
|------|---------|---------|------|
| **标准工兵** | 普通 | 完整 | 建造/排雷/爆破/修复全功能 |
| **战斗工兵** | 较强 | 有限 | 只能排雷和简单爆破，擅长CQB |
| **突击工兵** | 很强 | 极有限 | 专精CQB和攻坚，携带喷火器/炸药，几乎不做工程 |

### 20.3 可建造物

| 建筑 | 耗时 | 消耗 | 效果 |
|------|------|------|------|
| **战壕** | 即时 | 3AP + 备件 | 为所在格提供额外掩护减伤 |
| **地雷区** | 即时 | 3AP + 备件 | 敌方部队进入→受伤 + 停止移动 |
| **桥梁** | 持续2回合 | 备件 | 修复/架设可通行的桥梁 |

**建造规则**：
- 工兵部队在目标格执行建造指令
- 战壕和地雷区即时完成（消耗3AP和备件）
- 桥梁需工兵停留在该格2回合（移动则重置进度）
- 一个工兵部队同时只能建造一个工程

### 20.4 可破坏物

| 目标 | 方式 | 结果 |
|------|------|------|
| 城市建筑 | 工兵爆破 / 炮击 | 变为废墟地形 |
| 桥梁 | 工兵爆破 | 不可通行，需工兵修复 |
| 敌方地雷区 | 工兵排雷（停留1回合） | 清除地雷 |
| 敌方战壕/障碍 | 工兵拆除 | 清除防御工事 |
| 机场跑道/设施 | 工兵爆破 | 影响空中单位起降 |

### 20.5 反工兵能力

工兵可执行：
- **排雷**：进入地雷区格，停留1回合后清除
- **拆除障碍**：拆除敌方路障/反坦克障碍
- **修复建筑**：修复被破坏的建筑/桥梁
- **破坏设施**：拆除敌方建造的防御工事

### 20.6 地雷区规则

- 敌方部队进入地雷区 → **触发地雷** → 受到伤害 + **立即停止移动**
- 工兵可排雷（停留1回合）
- 地雷区不区分敌我：己方部队踩到同样触发
- 一个地雷区消耗一次后消失（触发一次即失效）

## 21. 空中单位系统

### 21.1 直升机定位

直升机不属于空军，而是**特殊的陆军载具部队**：
- 不需要机场，像地面部队一样部署和操作
- 可飞越地形（无视移动障碍和ZOC）
- 使用和地面部队相同的规则体系（补给、弹药、HP等）
- 不占用独立名额，与陆军统一出战名额

### 21.2 空军定位

固定翼飞机属于**空军部队**：
- 需要机场起降
- 空军编队 = 一支部队，内部多个飞机成员（如3× Bf-109）
- 与陆军**共用出战名额**（无独立空军名额）

### 21.3 飞机分类（多维度）

| 维度 | 分类 | 说明 |
|------|------|------|
| 重量 | 轻型 / 重型 | 决定机场需求和燃料消耗率 |
| 机翼 | 固定翼 / 直升机 | 直升机归为陆军载具 |
| 职能 | 战斗机 / 攻击机 / 轰炸机 / 运输机 | 决定武器配置和战术用途 |

### 21.4 机场系统

| 等级 | 功能 | 获取 | 可起降机型 |
|------|------|------|-----------|
| 简易机场 | 轻型飞机 | 工兵建造 | 战斗机、轻型攻击机、侦察机、轻型运输机 |
| 高级机场 | 全部飞机 | 城市/港口/大国基地 | 全部机型（含重型轰炸机/中型轰炸机） |

- 玩家必须**控制**（占领或己方）机场才能使用
- 战斗开始时，空军部署在己方机场格（从机场起飞）
- 战斗中夺取新机场后，可从该机场部署空军
- 机场可通过工兵建造（部分地形）

### 21.5 燃料与补给

- 飞机每**回合消耗燃料**
- 燃料耗尽时，如不在机场格则**坠毁**（单位消灭）
- 返回机场后自动补给（燃料回满 + 弹药回满）
- 燃料由全局补给池中的燃料储备提供

### 21.6 对空武器

| 武器类型 | 对空能力 |
|---------|---------|
| 防空炮/高射炮 | 高效（高命中、高伤害） |
| 机枪(LMG/HMG) | 可对空，效率较低 |
| 步枪/冲锋枪/手枪 | 不可对空 |
| 坦克炮 | 部分可对空（需专用对空弹药） |

- 地面防空为**反应射击**（空中单位攻击或移动经过时自动触发）

### 21.7 直升机与补给

- 直升机不需要机场
- 使用和地面部队相同的补给规则（补给站/补给部队可补给）
- 直升机可在任何平坦地形着陆

## 22. 铁路移动系统

### 22.1 世界地图铁路

- 地图上有铁路线连接部分据点
- 部队沿铁路线移动时，**消耗回合数减半**

### 22.2 战斗地图铁路

- 特定格标记为铁路格（轨道标记）
- 部队在铁路格上移动，**AP消耗减半**（正常1AP→0.5AP）
- 无额外车站/装载机制（保持简洁）

### 22.3 工兵互动

| 操作 | 说明 |
|------|------|
| 修复铁路 | 工兵修复被破坏的铁路段 |
| 破坏铁路 | 工兵破坏敌方铁路段，使其不可通行 |

## 23. 技能系统

### 23.1 技能来源

| 来源 | 说明 |

| 急救包 | 急救 | 主动(1AP) | 防止阵亡成员立即死亡（需在当回合内） |

| 工兵工具 | 排除 | 主动(2AP) | 排雷/拆除障碍 |
| 喷火器 | CQB烈焰 | 主动(2AP) | 对相邻格敌人造成范围伤害，无视掩体 |

### 23.3 指挥官技能重叠

| 情况 | 处理 |
|------|------|
| 指挥官有被动buff（如+5%命中） | 该部队全体成员生效 |
| 指挥官有主动技能（如治疗） | 部队获得该技能，即使没有对应装备的成员 |
| 指挥官技能与成员同类技能共存 | 效果增强（如压制射击的压制值+50%） |

### 23.4 技能与现有系统的关系

| 技能 | 关联系统 |
|------|---------|
| 压制射击 | §18 火力压制系统（快速积累压制值） |
| 爆破 | §20 工兵可破坏建筑 |
| 烟幕掩护 | §7 视野系统（阻挡视线） |
| 侦查标记 | §7 侦查技能（提升对该目标的命中/伤害） |
| 建造/排除 | §20 工兵建造与反工兵 |
