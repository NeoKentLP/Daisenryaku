> Godot 4.6.2 项目
> 定义所有UI控件的统一视觉规范，确保全游戏界面风格一致。

## 2. 字号层级

| 层级 | 大小 | 用途 |
|------|------|------|
| L0 标题 | 14-16px | 弹窗标题栏 |
| L1 区块标题 | 12px | 模块标题（■ 战况修正等） |
| L2 正文 | 11px | 属性值、列表内容 |
| L3 辅助 | 10px | 描述文字、状态信息 |
| L4 标注 | 9px | HP条文字、标签、注释 |
| L5 极小 | 8px | 弹药余量、悬浮提示辅助行 |

> Godot 中 `add_theme_font_size_override("font_size", X)`

## 7. 命名约定 (代码中)

| 约定 | 说明 |
|------|------|
| `_变量` | 私有变量（下划线前缀） |
| UI控件变量 | 以类型结尾: `_panel`, `_btn`, `_lbl` |
| StyleBox变量 | `_sb_` 前缀 |
| 主题常量 | `COLOR_` / `FONT_SIZE_` 大写前缀 |

## 9. UI设计规则

每次设计UI时遵守以下规则：

### 9.1 布局规则

1. **弹窗宽度**：左右留足够边距（≥200px），适应不同语言的文字长度差异
2. **信息层级**：标题→区块标题→属性→详细列表，从上到下信息密度递增
3. **tooltip定位**：弹出内容在容器上方，避免被父容器overflow裁剪；用fixed定位+JS计算
4. **属性显示**：只显示有实际值的条目（+0%的不显示），精简信息密度

### 9.2 交互规则

1. 所有可交互元素（按钮、可点击数据）hover时亮显
2. tooltip悬浮显示额外信息，不占用主UI空间
3. 状态类数据（士气、压制）的名称和数值都带tooltip

### 9.3 开发规则

1. 先在 `ui_prototypes/` 下创建HTML原型讨论
2. 确认后再在Godot中使用 `scripts/ui/ui_style.gd` 提供的样式函数实现
3. 同一界面的多个版本保留HTML文件供回溯
