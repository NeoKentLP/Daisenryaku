## 6. tscn 注意事项

### 6.1 Color 必须 4 参数

Godot Steam 版 tscn 解析器不支持 `Color(r, g, b)` 简写。
所有 tscn 中的 Color 必须写满 4 参数：
```
Color(1, 1, 1, 1)          # ✓ 正确
Color(1, 1, 1)              # ✗ 解析失败
Color(1, 1, 1, 0.03)       # ✓ 半透明白
```

### 6.2 全屏界面使用 CanvasLayer

主菜单、国家选择等用 `CanvasLayer` 作为根节点，其子节点使用锚点布局。

### 6.3 StyleBox 用 sub_resource

按钮、面板、卡片的 StyleBoxFlat 定义为 tscn 中的 `[sub_resource]`，
不要在代码中创建。

### 6.4 ext_resource 顺序与 UID

```
[gd_scene]           # 1. 文件头
[ext_resource ...]    # 2. 外部资源引用（在 sub_resource 之前！）
[sub_resource ...]    # 3. 子资源
[node ...]            # 4. 节点定义
```

- ext_resource 的 `uid=` 必须与 `.gd.uid` 文件一致。
  若 UID 不匹配，编辑器保存时会删除该引用，导致场景丢失脚本。
  **优先省略 uid**，仅用文本路径 + 让编辑器自动补全：
  ```
  [ext_resource type="Script" path="res://scripts/ui/xxx.gd" id="1"]
  ```

### 6.5 唯一名称引用

用 `unique_name_in_owner = true` + tscn 静态节点，脚本中用 `@onready var %Xxx` 引用。

### 6.6 按钮文字用子节点

需要双行（中文+英文）的按钮，LabelCN / LabelEN 作为 Button 的直接子节点，
使用 `layout_mode = 1` + 锚点填充。

## 7. 标题与文字样式

### 7.1 全屏界面标题

游戏主标题 "大战略"：52px，白色，SystemFont bold 700。
副标题 "— GRAND STRATEGY —"：14px，`#8CA1C6`，letter_spacing=4px。
中间分隔线：160×1px，`rgba(0.55, 0.63, 0.78, 0.2)`。

### 7.2 弹窗标题栏

14px，高亮色 `#77aaff`，紧接步骤指示 "第1步/共2步"（10px 灰色），
标题下 1px 分隔线。

## 8. 字体

| 用途 | 字体 |
|------|------|
| 全系统 | 系统默认 sans-serif |
| 粗体 | `SystemFont` font_weight=700，代码中创建 |

由于 Steam 版不支持 tscn 中的 `SystemFont` sub_resource，
粗体必须在 `.gd` 脚本中用 `_bold_font()` + `add_theme_font_override()` 设置。

---

## 9. 阴影

- 弹窗: `0 0 60px rgba(0,0,0,0.8)`
- Tooltip: `0 0 8px rgba(0,0,0,0.5)`
（Godot 中用 StyleBoxFlat 的 shadow 属性实现）

## 10. 验证

每次修改全屏/弹窗 UI 后，运行 `--check-only` 验证 tscn 解析：
```
$godot --headless --path <project> --check-only scenes/ui/xxx.tscn
```
